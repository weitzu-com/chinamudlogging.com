# A 版产品与询价页面：需求及验收

## 需求规格

- 用户授权：将产品列表、产品详情、询价页统一为 A 版深色工业风，保留七语与现有询盘功能，检查后上线。
- 目标与受众：油田工程师和设备采购沿“查找设备→查看技术资料→询价”路径获得一致体验。
- 设计目标：已上线 A 版首页及 Refero 锁定方向；复用黑底、白字、细边框和红色主操作按钮，不再探索新方向。
- 页面范围：含 `cml/catalogue` 的目录页、`cml_family` 分类页、所有 `cml_product` 详情、含 `cml/inquiry` 的询价页；七语同一套条件加载样式。
- 技术栈：现有 WordPress / cml 区块主题 / Polylang / cml-core / cml-hubspot；仅新增主题识别和 CSS，不替换业务插件、内容、译文或 SEO 扩展。
- 功能约束：搜索、分类、分页、产品参数、产品值预填、HubSpot 按需加载与独立链接、本站表单的验证/保存/防重/状态提示保持现状。第三方跨域嵌入内部由 HubSpot 控制，不强制改写。
- 交付：三个主题文件、预览与回归记录、生产前备份、明确发布清单、生产哈希与浏览器验收、截图及文件回滚路径。

## 可复用流程
