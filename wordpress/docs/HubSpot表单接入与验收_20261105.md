## 恢复后的验收步骤

1. 在可访问 Google reCAPTCHA 的网络中打开正式 `/contact-us/`，加载表单；若出现验证码挑战，由用户完成或按当次授权处理。
2. 按测试标识确认 CRM 中是否已有记录，避免盲目重复提交。优先从官网内嵌表单实测，独立页面成功不能替代官网来源验证。
3. 提交明确的 TEST ONLY 需求，记录成功回执与时间。
4. 在 HubSpot 表单提交列表和 CONTACT 属性 `mud_logging_inquiry_details` 中核对同一标识、邮箱和正文。
5. 在 sales@cnps.com 的收件箱或 Zoho 接收方投递日志核对通知主题、时间、Message-ID、最终 MAILBOX DELIVERY 和垃圾邮件状态。SMTP 接受或 HubSpot 提交计数不等同于邮件送达。
