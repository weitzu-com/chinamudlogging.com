四类证据收齐后，使用真实当前时间追加执行记录：


## 每轮范围

1. 读取最新 sitemap，核对上轮新增、删除、语言分布、lastmod、媒体及关键旧 URL/301。检查七语首页、分类、10 个重点产品、询价入口，robots、canonical、hreflang、sitemap、预览保护。实际 HTTP 和浏览器结果优先于历史告警。用户默认 Ego Lite；复用同一任务空间，顺序访问。无界批量访问可能触发 SiteGround 保护，不关闭防护。
2. 使用 OpenSEO 项目 `0d1817c7-a5b5-4f59-845b-b881f33b9950` 已连接的 `sc-domain:chinamudlogging.com` 属性，只读且不消费研究积分。GSC 本地 MCP 若是另一账号，不扩权、不重置认证。通过 `inspect_urls` 每批最多 10 条，以不超过两批并发覆盖当前 sitemap；保存逐 URL 原始结果、observedAt 和 locale。193/459 是 11 月 5 日一次基线，不是未来目标或整个域名索引总数。
3. URL Inspection 是 Google 最近索引快照，不是实时抓取。区分已收录、已发现未收录、已抓取未收录、未知、API 错误；比较 Google canonical、user canonical、最近抓取时间与当前 lastmod。已收录但抓取早于更新仍待新内容抓取。mobile verdict unspecified 不当作手机故障。正常等待不反复改内容或撤稿；不使用仅适用于特定职位/直播页面的 Google Indexing API 推送普通产品。
4. Search Analytics 使用 final 数据、太平洋日期。查询 date、page、query、device、country，必要时 query+page；检查 hasMore 并分页。财务或访问隐私数据仅保存私有目录。比较等长完整窗口，保留近期不完整状态；11 月 5 日可得的 10/06—11/02 是迁移前数据，不可归因新站。查询词明细有匿名过滤，不当作属性总数；国家不代表页面语言。不得将 GSC 点击与 UTC 匿名会话直接相除计算转化率。
5. 真实询盘并行核对：原生 WordPress 数据库的保存/邮件状态、匿名漏斗及只读 Zoho 同步健康、HubSpot 的录井需求字段候选。三者覆盖不同，不加总去重前的记录、不以联系人数量代替提交次数。明确 TEST ONLY、保留测试域名和验收标识单独排除；无明确标识为“待人工审核”，不能自动认定有效或垃圾。仅输出聚合或匿名 ID，不读取无关 CRM/私人邮箱；不向客户发信。SMTP accepted 不等于实际邮箱送达。当前日为部分 UTC 日，切换日混有切换前会话须单列。
6. 检查统计路径覆盖：`node wordpress/scripts/update-measurement-paths.mjs PRIVATE_INVENTORY.json --check`，输入为带 urls 数组的线上清单。新增产品必须更新精确路径清单并隔离测试；不接受任意 URL、查询参数、草稿或个人信息。隐私选择、广告拦截、无 referrer 和未关联邮件仍有缺口。历史漏记不能回填成真实访问。

## 自动修复边界

本次用户授权包含可证明的技术故障修复。先在同步域之外独立 clone/fetch 最新 `origin/codex/wordpress-migration`，核对线上与源码版本，保留并行改动、后台内容和失败证据。允许最小化修复 HTTP/重定向、canonical/语言关联、sitemap、已证实的 UI/表单故障、统计覆盖；备份、隔离测试、部署、生产复测和回滚说明齐全才结案。不得仅为正常索引等待批量重写内容、编造参数/认证、改 DNS/邮件路由/权限、删除询盘、自动有效性审核或发送客户邮件。不新增付费订阅或跟踪任务。

Worker 修改使用现有 `workers/funnel/wrangler.jsonc`，保留绑定和 secrets；先下载生产脚本及 deployments/版本记录，运行 `npm run test:funnel`、必要的 CI。回滚可对保留版本运行 `wrangler rollback VERSION --config workers/funnel/wrangler.jsonc`；它只回滚 Worker，不回滚 D1 数据。仅在同一变更造成故障且生产版本仍是本次版本时执行，避免覆盖并行部署。
