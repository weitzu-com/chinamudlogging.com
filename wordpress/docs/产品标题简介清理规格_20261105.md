# 产品标题与简介清理

- 目标：清除公开产品标题、简介中的 slug、文件名、重复品名、截断粘贴与过期内部占位文字，依据已保留且可对应到本记录的资料改写。
- 受众：油田工程师、采购及七语国际访客。
- 范围与约束：逐条核对公开记录和原始资料；缺乏证据的型号、性能、认证不推测。保持 URL/slug、SKU、规格、图片、翻译关系和询盘逻辑；七语均审计，只改确有问题的记录。
- 技术栈与站点：现有 SiteGround WordPress、cml Core/主题、Polylang、Yoast、HubSpot/本站询盘；www.chinamudlogging.com。
- 复用：WordPress 运维手册、本站部署与回滚手册、来源与缺口台账、既有内容/选型扩展和隔离验收。
- 交付：审计与 before/after/来源清单、受控幂等修复脚本、备份、预览和生产检查记录。
- 完成判据：公开占位文案消除；每条新文案可说明依据；无不明数字或型号扩充；七语路由、询盘预填/保存回归通过。部署前重新比较字段，拒绝覆盖并发编辑；回滚按修改字段恢复，不整库覆盖新询盘。

## 审计与处置

375 条公开记录已审计。选中 267 条英文记录：56 条旧目录记录清除重复品名、slug、截断段落、公司模板与标题可读性问题；211 条导入记录按其明确的来源名称区分传感器、探头、板卡、支架、连接件、线缆、电池/充电器等用途，不从型号识别串推导性能。共改 47 个标题、267 条简介；其余 108 条（含全部 60 条非英语产品记录、9 条手册和已有审阅改写）保持。

与旧简介相同或为空的 267 条 Yoast 描述同步使用新简介；独立维护的 SEO 标题与既有选型扩展继续保留。正文、原始描述 meta、SKU、规格、分类、首图、翻译关系和 URL 均受保护。

产品 125 使用未知型号识别说明，并保留 AI 示意图声明。CNPS-MHP 标题出现 15,000 psi，而保留正文写有另一量程，本轮移除标题中的未确认量程，明确要求核实型号、量程和接口；不修改来源规格原文。

完整可审阅计划见 `../content-repairs/product-copy-plan-20261105.json`；其中包含逐条 before/after、来源及受保护字段/正文指纹。来源名称只支持部件身份与用途，并不证明所供版本的范围、精度或认证。

## 执行与验证

`prepare-product-copy.py` 从私有只读库存及 SEO 库存生成计划。`apply-product-copy.php` 先检查全部目标，再逐项复查；只更新标题/简介及计划中的 SEO 描述，不更新整条来源记录。保存过程精确保留比较符号与原文；重试幂等，发现并发文案或型号变更即停止。先 dry-run，备份及隔离验证通过后 apply。

专门的隔离 WordPress 测试覆盖批量预检、幂等、并发保护、原文/规格/SKU保留、比较符号、未知型号不推断、slug/模板消除和全部计划范围。真实浏览器回归覆盖目录卡片、详情首屏、长标题、七语询盘预填和阿语 RTL。原始正文中的历史来源文本保留，不以此冒充新撰技术资料。
