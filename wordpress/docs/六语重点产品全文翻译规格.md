# 六语重点产品全文翻译

- 目标与用户：将既定 10 个重点产品的六语选型摘要升级为全文，帮助采购商和工程师理解用途、结构、安装维护及参数。
- 数据：冻结的 src/data/products.json，不扩大到并发新增产品。逐段记录英文原文、翻译输入和 SHA256，旧译稿不直接批准。
- 术语：区分录井和井下测井，固定岩屑、钻井液、泵冲、差压、变送器、采集系统等六语词表。型号、符号、数值精度、单位、接口代码保持源写法。
- 源错误：不猜补单位、不调换不等号、不默改认证或温度换算；在对应译文注明选型确认点。旧资料声明归属于原来源，不变成平台自证。
- 可见范围：仅 60 个已有公开产品，保留 URL、图片、分类、语言关联及询价链路。不覆盖其他编辑内容，不创建占位页。凭据、缓存和备份不入 Git。
- 验收：段落完整对应，数值/符号/单位/型号逐段一致；术语和英文残留检查；表格、RTL、canonical/hreflang、询价预填、手机布局和实际正文核对通过。
- 部署：先备份，全批预检人工编辑冲突及英文基线，只更新指定产品正文和全文状态；通过门禁自动发布，清缓存，验证实际哈希。逐产品保留回滚记录，重跑不增副本。
- 证据边界：AI 翻译与技术一致性校核，不冒充制造商确认或母语审校签字；明确保留源资料未决项。
