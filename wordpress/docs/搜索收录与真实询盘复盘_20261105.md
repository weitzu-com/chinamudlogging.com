## 瓶颈与取舍

1. 可观察的首要获客限制是搜索规模及商业目录/整机词排名，样本不足以证明标题或表单导致流失。新内容刚发布，先保障Google能正确识别和发现更新，避免当天反复重写。
2. 已确认的技术问题：GSC温度页产品摘要提示必须提供offers/review/aggregateRating。现有Core给所有产品输出不含这些字段的Product候选；产品仍已收录，富结果错误不是未收录的原因。
3. 更新信号缺口：选型内容由插件渲染，CMS正文时间未变；公开产品sitemap仍把温度、计算机、监测、评价等标为2026-11-04 08:33 UTC。本轮改动结构化数据，使用实际固定源修订时间同步表达，不伪装每日更新，不重写数据库post_modified。
4. 下游目前缺少足够真实意向/收件样本，不能判定收件故障或有效率。人工有效审核边界不变。

后续URL检查确认：雷达液位仍“已发现 - 尚未编入索引”，泥浆传感器分类仍“已抓取 - 尚未编入索引”（界面上次抓取8月29日）。公开分类首屏是12个通用型号卡片、共15页，原选型重点产品分散在分页中，尚无测量变量路由。它构成可直接改善的发现和采购决策缺口，不把新指南上线等同Google接受收录。

Google官方依据：[产品摘要要求](https://developers.google.com/search/docs/appearance/structured-data/product-snippet)说明至少具备offers、review或aggregateRating之一；[sitemap lastmod说明](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)允许对真实正文、结构化数据或链接的重要改动标注修改时间。移除Product候选不等于新增产品富结果资格，Google重抓/清除历史告警仍待后续观察。
