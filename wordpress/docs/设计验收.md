## 问题与处理

阻断：已检查范围无未解决项。已修复按钮文字对比度、语言与手机菜单触控高度、自动填充字段、当前栏目标识，以及 Insights 缺少 H1。

警告：网络或服务器校验失败时显示本语言的统一说明及直接邮箱入口，尚未把服务器错误逐项绑定到具体字段。浏览器原生 required/email 约束负责即时字段提示。

建议：WordPress 与本站各提供一个跳转到正文的链接，键盘使用存在一次冗余跳转；二者都指向有效 main，不阻断正文访问。

## 验证证据与限制

实际 HTTP 验收覆盖 181 条内容、35 个语言分类、167 条媒体来源路径、8 条历史页面重定向和 sitemap。未把样式加载前的临时未排版宽度算作最终溢出；最终截图与布局测量在样式加载后完成。

表单 REST 已完成七语保存与重复回执检查；真实 MySQL 上强制发送失败后记录仍然存在。邮件送达证据单独记录在迁移验收报告，不用视觉审查替代收件核验。

未进行全套屏幕阅读器、所有移动设备和所有浏览器组合测试。后续设计改动继续使用相同的窄屏、RTL、对比度与表单状态检查。
