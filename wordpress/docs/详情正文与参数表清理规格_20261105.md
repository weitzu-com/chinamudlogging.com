# 详情正文与参数表清理

- 目标：清除公开详情的 slug/导入占位、重复说明、明显翻译腔及不清楚的参数标签，按能对应到本记录的来源重新组织正文与参数表。
- 受众：油田工程师、设备采购与七语国际访客。
- 约束：不从型号或目录识别串推导参数；冲突、残缺或单位不明值标为待确认。保留 URL、图片、标题/简介、七语关系和询盘逻辑/数据；原始正文与参数数据留存可追溯，拒绝覆盖并发编辑。
- 技术栈：现有 SiteGround WordPress、cml 主题/Core、Polylang、Yoast、HubSpot/本站询盘；www.chinamudlogging.com。
- 复用：原点 WordPress 运维手册、部署/回滚手册、来源与缺口台账、既有选型扩展、上轮逐字段保护与真实七语预览流程。
- 交付：全量审计、来源/参数处置映射、简洁详情正文与参数表、备份、隔离与线上回归、回滚记录。
- 方法：优先使用受来源指纹保护的展示层整理，保留后台原文和原始参数，不让旧的重复正文/机械翻译继续占据主详情。目录识别信息与技术数值分开，供应版本仍须确认。原始数据变动时不静默套用旧审阅结果。
