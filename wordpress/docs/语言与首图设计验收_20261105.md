| 检查类 | 结果 |
|---|---|
| 字体、色彩、间距、层级 | 深色 A 背景、白字与灰色辅助文字；主操作保留；产品图 4:3，无畸变 |
| 一致性、无障碍 | 原生 dialog 焦点隔离、可访问名称、Escape、44px 控件、关闭后返回焦点；设备图片保留 alt |
| 表单、状态 | 原后台保存、邮件失败留存、防重与校验不改；隔离 240 项通过 |
| 动效 | 新增组件无位移动画，不引入必要的减弱动态设置 |
| 深色、响应式 | 320px 七语询盘页无水平溢出，桌面四栏、窄屏两栏面板 |
| 图标、微文案 | globe 图标具可访问名称；页面/目录跳转说明准确 |
| 阴影、圆角 | 轻边框和暗遮罩，延续 A 版；无多层嵌套圆角问题 |
| 国际化、导航 | 七语原生名称、阿语 RTL、已译产品同页切换、缺译目录回退、无 JS 链接 |
| 令牌、伦理、易用性 | 复用 A 版色值，无强制地域跳转、无新增追踪 cookie；不把图片生成当成设备证据 |
