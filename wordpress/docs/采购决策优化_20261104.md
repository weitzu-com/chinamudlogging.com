# 产品目录与录井系统采购决策优化

## 规格

- 目标：增加有采购意图查询与两类商业落地页的匹配度，帮助采购者形成可报价需求。
- 用户：英文国际油田采购、录井系统集成及备件负责人。
- 数据：2026-11-04 从 GSC 导出的 10-05 至 11-01 CSV；logging unit 11展示/排名66.18，mud logging unit 8/43.88，mud logging equipment 3/12，drilling monitoring systems 2/3.5；样本小，不将其当市场需求总量。
- 范围：WordPress 正式站 `/product/` 和 `/product-category/mud-logging-units/` 的未筛选第一页。其余语言、搜索结果和分页不重复插入英文指南。
- 内容：采购路线对照、系统边界、需求核对表、真实产品与知识页内链、预填产品询价。无新规格、认证、价格、交期承诺。
- 可见范围：采购指南公开；客户资料和投递证据保持受保护；有效询盘仅人工审核。
- 部署：独立 MU 扩展 `wordpress/extensions/cml-buyer-guide.php`，只增加单文件，不覆盖正在维护的 Core、主题、数据库页面或迁移包。部署前校验现有文件及远端备份，部署后核对 SHA256、页面、链接、移动端和询盘预填。
- 成效：按来源×落地页 cohort 追踪访问、意向、实际 Zoho 收件、有效和待审。提交、SMTP接纳、索引请求均不冒充其后阶段。比较完整窗口及样本数；收录状态以 GSC URL 检查为准。
