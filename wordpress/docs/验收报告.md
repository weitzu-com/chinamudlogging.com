## 询盘与邮件证据

七语各完成服务器保存和重复提交验证，重复请求返回同一回执。通过本站既有只读 Zoho SMTP 投递日志接口，逐一匹配七语回执，7/7 为接收方 MAILBOX DELIVERY / delivered，垃圾邮件标记均为 No。

询盘通知使用本站专用 DKIM 签名，并经强制 STARTTLS、验证证书的 SMTP 直达现有 Zoho 收件域 MX。服务器本地 `mail` 路径的切换后测试未及时出现收件证明，已替换为实际验证的直达路径。WP Mail SMTP 保留 `mail` 作为其他 WordPress 通知的默认传输；未配置外部账号密码的 SMTP 中继。实测 DKIM 与 DMARC 通过，既有 SPF 保留，不能描述成 SPF 通过。未重置邮箱密码、创建委托或复制其他站点密码。sales@chinamudlogging.com 已确认为现有 Zoho Sales 邮箱别名。

部分测试经过数十分钟才出现在收件侧，当前证据不足以确定延迟发生在哪一环节。`transport_accepted` 只表示传输接受，后台数据库才是保存询盘的真值；客户界面只确认“已保存”。即使通知失败，需求仍保留。正式浏览器另提交一条隔离测试，已保存并与 is_test=1 的匿名统计意向关联；该回执于 UTC 08:35:37 在 Zoho 确认 MAILBOX DELIVERY，非垃圾邮件；最终生产配置另以浏览器提交回执 11caf694-ccc5-4a25-b3c0-4753f7e50085，UTC 08:40:51 保存、08:40:54.600 实际送达，08:45:54.271 自动关联投递证据；约 3 秒送达且非垃圾邮件。最终统计关联证据记录在上线观察中。
